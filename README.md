This catalog collects practical diagramming and whiteboarding tooling: browser-native whiteboards, local-first diagramming, open timeline interchange, and editor surfaces where drawing is first-class. Every entry keeps your visual artifacts on your own infrastructure. Check each upstream repository for its current license and release status.

---

### Whiteboards & Visual Thinking

* **[tldraw](https://github.com/tldraw/tldraw)** — Infinite canvas library with collaborative primitives; embeddable in your own apps.
* **[excalidraw](https://github.com/excalidraw/excalidraw)** — Hand-drawn-style whiteboard with collaborative editing and self-hostable deployments.
* **[excalidraw-room](https://github.com/excalidraw/excalidraw-room)** — Self-hosted persistence and rooms layer for Excalidraw.
* **[Neoflow](https://github.com/kiraaziz/Neoflow)** — Open-source whiteboard for visual thinking with structured node linking.
* **[pad.ws](https://github.com/coderamp-labs/pad.ws)** — Browser whiteboard that doubles as an IDE for live pair design.

### Diagramming & Modeling

* **[drawio](https://github.com/jgraph/drawio)** — Mature diagramming suite for flowcharts, network, BPMN, and ER diagrams.
* **[mermaid](https://github.com/mermaid-js/mermaid)** — Markdown-like syntax that renders diagrams and flowcharts from text.
* **[mermaid-cli](https://github.com/mermaid-js/mermaid-cli)** — Command-line wrapper to generate Mermaid diagrams as PNG/SVG/PDF.
* **[penrose](https://github.com/penrose/penrose)** — Create beautiful diagrams from simple mathematical specifications.
* **[bpmn-js](https://github.com/bpmn-io/bpmn-js)** — BPMN 2.0 modeling and rendering library for the browser.

### Graph & Topology Visualization

* **[cytoscape.js](https://github.com/cytoscape/cytoscape.js)** — Graph-theory library for analysis and visualization in the browser.
* **[rete](https://github.com/retejs/rete)** — Node editor framework for visual programming in the browser.
* **[jsplumb](https://github.com/jsplumb/jsplumb)** — Toolkit for connecting UI elements with lines, arrows, and Bezier paths.
* **[G6](https://github.com/antvis/G6)** — AntV graph visualization engine for relational and networked data.
* **[mlt](https://github.com/mltframework/mlt)** — Multi-purpose media framework for video and timeline editing.

### Editor Surfaces & Document Tools

* **[twenty](https://github.com/twentyhq/twenty)** — Open-source CRM alternative to Salesforce with first-class data-shape work.
* **[phoenix](https://github.com/phcode-dev/phoenix)** — Text editor with built-in drawing and live-preview support.
* **[asciidoctor-diagram](https://github.com/asciidoctor/asciidoctor-diagram)** — AsciiDoctor extension that embeds Mermaid, PlantUML, and Graphviz.
* **[markmap](https://github.com/markmap/markmap)** — Mind-map visualization built from Markdown outlines in the browser.
* **[markdoc](https://github.com/markdoc/markdoc)** — Markdown-based authoring framework with extensible node rendering.

### Open Standards & Interchange

* **[OpenTimelineIO](https://github.com/AcademySoftwareFoundation/OpenTimelineIO)** — Open API and interchange format for editorial timeline data.
* **[patternfly-elements](https://github.com/patternfly/patternfly-elements)** — Web component library with diagrammatic and chart primitives.
