# Contributing

Contributions are welcome when they fit the catalog's theme and the edljx principle: ditch the subscription, keep the productivity.

Please open an issue or pull request with:

- the upstream repository URL;
- a short factual description;
- the section where it belongs;
- its current license, if known;
- a note explaining why it is a useful alternative to a paid or cloud-first tool.

Please verify that the repository is active, relevant, and not already listed before submitting it.
